Concurrency guarantee

The 2-second cadence never stalls. One single-threaded event loop orchestrates; CPU-bound inference is pushed to worker threads; the heavy STT+LLM runs in a throttled background task. So a slow model — or one slow call — can't block the stream or the other calls.

Fail-safe orchestration

Every layer is wrapped: an error or a missing dependency (no STT, no LLM key, offline) makes that signal neutral and the verdict still ships. Missing neural weights → CNN fallback. No single layer can take the pipeline down.
